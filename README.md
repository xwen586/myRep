# 俄罗斯方块简易版（HTML/CSS/JavaScript）

## 如何运行

这个项目是纯前端单文件实现（`index.html`），不依赖打包工具。

### 方式一：直接双击打开（最简单）
1. 进入仓库目录。
2. 直接用浏览器打开 `index.html`。

### 方式二：本地起一个静态服务（推荐）
在仓库根目录执行：

```bash
python3 -m http.server 4173
```

然后在浏览器访问：

```text
http://127.0.0.1:4173/index.html
```

## 游戏操作

- `←` / `→`：左右移动
- `↑`：旋转方块
- `↓`：加速下落
- `空格`：直接落到底部
- `P`：暂停 / 继续

## 界面按钮

- **开始 / 继续**：开始游戏或从暂停恢复
- **暂停**：暂停当前游戏
- **重新开始**：清空并重新开局
